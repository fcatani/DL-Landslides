# DL-Landslides
Deep learning functions for landform detection from non-nadiral optical images which uses transfer learning and CNNs.
Input data is any collection of pictures of landforms labelled by splitting them into different sub-folders. 
Training needs only a few hundreds images for each class.
Tested for the following landforms or negatives:
1. Landslide
2. Rock cliff
3. Debris or scree slope deposit
4. Alluvial fan
5. Stable slope

Includes XAI explainability demonstration functions that make use of GRAD-CAM and Occlusion Sensitivity.
